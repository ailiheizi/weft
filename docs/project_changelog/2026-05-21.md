## packages/official/agent-core

### 新增：RequiredActionState 意图检测框架

从用户请求中检测必要工具意图，防止 agent 在完成所有要求前提前结束：

- `RequiredActionState`：追踪 needs_shell / needs_web_search / needs_web_fetch / needs_git_commit / needs_git_query 等 16 个字段
- `detect_git_commit_intent` / `detect_git_query_intent`：区分 git 查询和 git 提交意图
- `missing_actions()`：返回尚未满足的必要工具列表
- `build_required_action_prompt`：生成 follow-up prompt 推动 agent 继续执行

### 新增：Loop 检测

- 在 `execute_agent_turn_plan_loop` 中追踪每轮 tool_calls 的 fingerprint（`name:arguments_json` 拼接）
- 连续两轮完全相同时自动中止，返回 `[Stopped: repeated identical tool calls detected]`
- 防止模型卡死在重复工具调用循环

### 新增：Session Events 集成

- 新增 `SESSION_EVENTS_CAPABILITY` 常量和 `append_session_event` 函数
- Agent turn 过程中的关键事件写入 `session.events` capability
- `tool_args_preview`：工具参数预览（截断大参数）
- `truncate_event_text`：事件文本截断

### 新增：Evolved Skill 轨迹集成

- `promote_trajectory_skill`：turn 完成后自动将成功轨迹结晶为 evolved skill
- `record_evolved_skill_usage`：记录 skill 使用成功/失败
- `normalize_js_runtime_tool_name`：规范化 JS runtime 工具名

### 新增：Agent 管理 Actions

- `do_get_agents` / `do_create_agent` / `do_delete_agent`：agent 配置 CRUD
- `upsert_session_message_record`：会话消息持久化

### 新增：Session 辅助函数

- `default_memory_package` / `default_skills_package` / `default_channels_package`：默认包名
- `skills_package_candidates`：skills 包候选列表（支持 skills-runtime 别名）

### 其他

- `MAX_AGENT_TOOL_ROUNDS = 8`：最大工具调用轮数常量
- `host_call_package` 宿主函数：支持包间调用
- `plugin.toml` → `package.toml` 迁移

## packages/official/weft-claw

### 新增：cancel_turn 实现

原来硬编码返回 `cancelled: false`，现已实现软取消机制：

```rust
// 写 KV flag
kv_set("weft-claw:cancel:{session_id}", "1");
// 追加 cancelled 事件到 session.events
append_session_event(session_id, "task_status", {status: "cancelled"});
// send_message 开头自动清除 flag
kv_delete("weft-claw:cancel:{session_id}");
```

## packages/official/js-extension-runtime

### 大幅扩展搜索引擎支持（+147 行）

- `14e0284` Add JavaScript extension runtime package

**新增搜索 provider：**

| Provider | 实现方式 |
|---------|---------|
| Exa API | `searchExaApi` — 调用 `api.exa.ai/search`（REST API） |
| Exa MCP | `searchExaMcp` — 通过 MCP 调用 Exa |
| DuckDuckGo | `searchDuckDuckGo` — HTML 解析 + redirect 解包 |
| Bing | `searchBingHtml` — HTML 解析 |

**路由逻辑：**
```
resolveSearchQuery(args)
  → provider="exa": searchExaApi → fallback searchExaMcp
  → provider="duckduckgo": searchDuckDuckGo
  → provider="bing": searchBingHtml
  → 默认: Exa → DuckDuckGo → Bing 级联降级
```

**其他：**
- `decodeTransportBase64Text`：base64 编码查询支持
- `unwrapDuckDuckGoRedirect`：解包 DuckDuckGo 重定向 URL
- `isOrganicSearchResultUrl`：过滤广告/非自然结果
