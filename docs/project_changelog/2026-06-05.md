## core — 权限门控（A1）

### WASM host_fn 权限门控落地

- 文件：`src/package/bridge.rs`、`src/package/permissions.rs`
- 新增 `gate_permission!` / `gate_permission_unit!` 宏；`WasmHostState` 加 `permissions` 字段
- 13 处 host_fn 接入权限检查：read/write/list_dir + sqlite_×3 → Storage；exec_×2 + process_×5 → Process；chat_×2 → Network（kv/log 不 gate = 基础自有能力）
- `PackageLoadInfo` 加 `permissions`，4 处构造点 + 测试补全；数据流 package.toml → manifest → WasmHostState → PermissionChecker 闭环
- **运行时验证抓到 session-events 越权 storage**（静态审计漏判，sdk sqlite wrapper 不带 host_ 前缀）→ 补声明后 0 denial
- 修复：`load_package` / `reload_package`（hot-load 路径）漏注入 `permissions`（启动路径已对）

## core — 故障隔离沙箱（A2）

### per-package 熔断器

- 新增文件：`src/package/circuit_breaker.rs`（三态 Closed/Open/HalfOpen + 滑窗 + 冷却 + 半开探针，时间注入可测，6 单测）
- `bridge.rs`：两条 call 路径（`WasmPackageHost::call` + `WasmHandle::call`）接入 check/record；`unload_package` reset breaker
- "失败"定义为 host 侧 `Plugin::call` 的 Err（trap/panic），不含 guest 业务错误

## core — manifest validator（B1）

## core — 依赖 requires 完整性校验（B3）

## core — Core loopback token 鉴权（D2）

### /api/* 鉴权

- 文件：`src/api/mod.rs`、`src/api/openai_compat.rs`、`src/main.rs`、`src/api/package_ws.rs`、`src/bin/weft.rs`
