> **2026-05-27 决策：Demo 阶段暂缓** — "demo 不急着搞这些"
> 注：上线前必需的 ICP / 公安 / 大模型备案仍按法定要求处理，但等保三级 / SOC 2 等高级认证 Demo 阶段不投入。

### 国内合规清单
- **ICP 备案**（必须）
- **公安备案**（运营前）
- **算法推荐备案**（已要求）
- **生成式 AI 备案**（必须，2024 起强制）
- **等保三级**（B2B 销售必备）
- **个保法 PIA 评估**

### 海外合规清单
- **GDPR**（欧盟）
- **SOC 2 Type II**（北美企业销售必备）
- **ISO 27001**（国际通用）
- **HIPAA**（美国医疗）
- **DPF / Privacy Shield**（数据跨境）

### 实施节奏
- M1：ICP / 公安 / 大模型备案（必须，否则不能上线）
- M6：等保三级（推动 B2B 销售）
- M12：SOC 2 Type II（推动出海）

### 成本
- 国内合规一次性 ¥30-80 万 + 年维 ¥10 万
- SOC 2 一次性 $30-50K + 年审 $20K

### 优先级
**P0**（基础合规）+ **P1**（高级认证）

## 本章小结

商业 / 合规 / 增值层是**从"AI 工具"升级到"AI 平台"的必经之路**。

核心结论：
1. **基础合规要早做**（备案 / 等保），不然根本卖不进 B 端
2. **SSO + 审计 + RBAC** 是企业销售的"入场券"
3. **私有化 + 白标** 是 ARPU 拐点（一单顶 100 个个人用户）
4. **BYOK / BYOC / 期货** 是大客户偏好的高级模式
5. **海外合规（SOC 2 / GDPR）** 是 12 个月后的重点

> "**让客户能买、敢买、值得多买**" — 这一层不直接做产品功能，但决定了产品能不能赚到大钱。
