## 关键结论（先看这部分）

> **2026-05-27 决策对账概览**
> - 第一层（AI 能力）：多模型路由 / Embedding / 微调 ❌；BYOK / 搜索 / Function Calling / Prompt 缓存 ✅；多模态 ⚠️（仅图像+音乐）；OCR/ASR ✅（作为 tool）
> - 第二层（云资源）：✅ 全部通过 — "全部没问题"
> - 第三层（知识库）：团队空间 ❌（暂时）；其余 ✅（融入 Companion，不暴露独立模块）
> - 第四层（Agent）：编排器 / 监控 / 安全 ✅；长任务 / 多 Agent / 工作流编排 / 市场 / 触发器 / 模板库 ❌；自我演化 🕐
> - 第五层（行业垂直）：❌ 全部打回，不做解释
> - 第六层（商业合规）：🕐 Demo 阶段全部暂缓

1. **现有方案（DeepSeek 中转 + 云函数 + 网站托管 + 知识库）只覆盖到第一、第二层**，处于"卖资源"阶段，毛利薄、可替代。
2. 真正赚钱的钱在 **第四到第六层**（生态、行业、合规增值），毛利率 60-80%，且具备竞争壁垒。
3. 我们已有底座 WEFT-plug 的 **agent-core / tool-runtime-core / WASM 包系统**，正好就是支撑第四层的现成引擎，不重复造轮子。
4. 战略路径建议：**第一年先把 1-2-3 层做扎实拿到现金流，第二年集中火力打 4-5 层建立壁垒，第六层贯穿始终（合规越早越好）**。

## 投资视角

> Q1：要不要做生态层（Agent 市场）？
> **要**。冷启动慢但一旦起来就是网络效应，且我们 agent-core 现成。

> Q2：要不要做行业垂直版？
> **要 1-2 个就够**。建议先做"程序员"（WEFT 自身用户群天然重叠）+"自媒体"（多模态变现快）。

> Q3：要不要做企业私有化？
> **要**。一年签 5 个就回本，且现有 Server/Core 双进程架构天然适合离线交付。

> Q4：要不要做出海？
> **第一年不要，第二年要**。先把国内 Plus/Pro 跑通，再做新加坡节点 + GDPR。
