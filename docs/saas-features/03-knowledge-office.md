## 3.1 多端文件上云 ✅

> **2026-05-27 决策：通过（Companion 主体性）** — 文件入口能力保留，但不暴露独立"上传中心"按钮，融入 Companion 对话与行为里。

### 功能描述
- **桌面客户端**（Electron，已有）：拖拽 / 文件夹监听同步 / 选择性同步
- **Web 端**：浏览器拖拽上传 / 粘贴 / 截图
- **移动端**（iOS/Android，待开发）：拍照 / 录音 / 分享菜单接入
- **浏览器扩展**（Chrome/Edge）：一键收藏网页 / 选区 / 全文
- **邮件 / IM 入口**：转发邮件到专属地址，自动归档
- **API / CLI**：开发者批量导入

### 用户价值
- 文件不在某一台机器上，而是在"自己的 AI 大脑"里
- 任何场景遇到的信息，3 秒内可入库

### 技术实现
- 客户端用 OMC 的 Electron 基础 + rclone 风格的同步引擎
- 服务端入口：S3 兼容上传 + 分片续传 + 秒传去重（SHA-256）
- 上传后异步触发解析 / 索引流水线（见 3.2）

### 优先级
**P0**

## 3.2 异步解析 + 离线索引流水线 ✅

> **2026-05-27 决策：通过（作为 Companion 内部能力）** — 流水线作为后台能力存在，不暴露独立"索引管理"模块。

### 功能描述
- 用户上传不阻塞，后台慢慢处理（节省用户等待 + 节省计算峰值）
- 支持格式：
  - 文档：PDF / DOCX / PPTX / XLSX / EPUB / Markdown / TXT / HTML
  - 媒体：MP3 / MP4 / WAV / M4A（自动转写）
  - 图片：JPG / PNG / HEIC（自动 OCR + 描述）
  - 代码：所有主流语言（结构化分块）
- 流水线阶段：
  1. **解析**（pdf2text / python-pptx / ffmpeg / OCR / ASR）
  2. **清洗**（去页眉页脚 / 去广告 / 标准化）
  3. **分块**（语义切分，非固定字符）
  4. **向量化**（embedding）
  5. **图谱化**（实体抽取 + 关系，建知识图谱）
  6. **入库**（向量 + 倒排 + 图谱三路）

### 用户价值
- 一次上传，三种检索方式可用（语义 / 关键词 / 图谱）
- "离线"二字让用户感知"这是 AI 在为我工作"

### 技术实现
- 任务队列：NATS JetStream / Temporal
- 解析层：复用 OMC `pdf` / `ppocrv5` / `ffmpeg-usage` 等技能
- 向量层：自建 Qdrant 集群
- 图谱层：Neo4j Community 或 ArangoDB

### 定价建议

| 阶段 | RC |
|---|---|
| 解析（按 MB） | 5/MB |
| 向量化（按 token） | 0.02/1K |
| 图谱化（可选） | 10/MB |
| 索引存储 | 30/GB·月 |

### 优先级
**P0**

## 3.3 多模式检索（一键云检索） ✅

> **2026-05-27 决策：通过（融入 Companion 检索能力）** — 不暴露独立"搜索框"产品，作为 Companion 的内置检索行为。

### 功能描述
- **基础检索**：关键词匹配（BM25）
- **语义检索**：向量相似度
- **混合检索**：关键词 + 向量 + Rerank 三路融合（默认）
- **图谱检索**：基于实体关系的多跳问答
- **跨模态检索**：文字搜图、图搜图、声搜文
- **时间 / 标签过滤**：限定范围

### 用户价值
- 用户只看到一个搜索框，但背后是工业级 RAG
- 多端体验一致：桌面 / Web / 手机用同一个账户的 KB

### 技术实现
- 默认走"混合 + Rerank"，保证质量
- 高级用户可选模式

### 定价建议

| 类型 | RC/次 |
|---|---|
| 基础检索 | 2 |
| 混合 + Rerank | 5 |
| 图谱多跳 | 15 |
| 跨模态 | 10 |
| 含 LLM 生成答案 | + 模型档位价 |

### 优先级
**P0**

## 3.11 隐私 / 加密 / 私有索引 ✅

> **2026-05-27 决策：通过（基础能力）** — 隐私 / 加密作为底层基础设施保留。

### 功能描述
- 三种存储模式：
  - **标准**：服务端加密（默认）
  - **E2E**：端到端加密（密钥用户掌握，平台无法解密）
  - **本地索引**：向量库 + 文件都在用户本地，平台只做调度
- 法律 / 医疗 / 金融行业刚需

### 用户价值
- 解决"我的数据会不会被你拿去训练"这一终极疑虑
- 企业级安全合规

### 技术实现
- E2E：客户端 AES-256-GCM 加密后上传
- 本地索引：桌面客户端跑 sqlite-vec / lancedb

### 定价建议
- E2E 加价 30%（额外密钥管理成本）
- 本地索引免费但要装客户端

### 优先级
**P1**（M5，企业销售必备）

## 本章小结

知识库 / 办公层是**用户停留时长和粘性的核心**。设计思路：

1. **数据入口要多**：桌面 / Web / 移动 / 扩展 / 邮件 / IM 全覆盖
2. **离线索引要异步**：用户不等，平台慢慢算
3. **检索要多模态**：关键词 + 语义 + 图谱 + 跨模态
4. **引用要可追溯**：让 AI 答案可信
5. **隐私要可选**：标准 / E2E / 本地三档
6. **协作要原生**：从个人到团队的无缝升级

一旦用户把"几年的资料"放进来，他就走不掉了——这是 LTV 最高的产品线。
