## 7.0 决策框架

每个功能用 4 个维度打分（1-5 分），加权排序：

| 维度 | 权重 | 含义 |
|---|---|---|
| **收入贡献** | 35% | 能直接带来多少 GMV |
| **差异化** | 25% | 竞品没有 / 做不好的程度 |
| **实现成本** | 25% | 工程量 + 依赖复杂度（分越高越容易做） |
| **生态效应** | 15% | 对其他功能 / 用户增长的乘数效应 |

## 7.5 风险与应对

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 上游 API 涨价 50%+ | 中 | 高 | 多供应商 + 自建轻量模型 + 缓存 |
| 监管收紧（大模型备案变严） | 高 | 高 | 提前备案 + 法务顾问 + 双版本 |
| 巨头入场（字节/腾讯做类似产品） | 高 | 中 | 差异化（Agent 生态 + 垂直版）+ 速度 |
| 价格战（硅基流动等零利润） | 中 | 中 | 不打价格战，靠上层价值 |
| 技术债（WASM 包系统复杂度） | 中 | 中 | 持续重构 + 测试覆盖 |
| 团队流失 | 低 | 高 | 期权 + 文化 + 有竞争力的薪酬 |
| 数据泄露事件 | 低 | 极高 | 安全审计 + 保险 + 应急预案 |

## 7.6 不做清单（同样重要）

以下功能**明确不做或暂缓**，避免分散精力：

| 不做 | 原因 |
|---|---|
| 自研大模型 | 成本 > ¥1 亿，不是我们的战场 |
| 硬件（AI 芯片 / 一体机自研） | 资源不够 |
| 社交功能（朋友圈 / 动态） | 偏离核心 |
| 游戏 / 娱乐 | 偏离核心 |
| 通用 IM（做微信/飞书） | 红海 |
| 区块链 / Web3 | 不确定性太高 |
| 线下服务 | 不是互联网公司该做的 |
